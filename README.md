# image slicer for LLM

세로로 긴 웹페이지를 LLM에게 읽히려고 하면 두 가지 벽에 부딪힌다.

1. **전체 페이지 스크린샷이 잘린다.** 브라우저의 전체 페이지 캡처는 세로 길이·총 면적에
   한계가 있다. 파이어폭스는 세로 1만 px 언저리에서 잘리기 시작하는데, 블로그 글 하나가
   3만 px를 넘는 건 흔하다.
2. **올려도 글자를 못 읽는다.** LLM은 긴 변을 기준으로 이미지를 축소한다.
   `1440x12000` 스크린샷은 가로가 190px 수준으로 뭉개져서 아무것도 읽을 수 없다.

이 CLI는 둘 다 해결한다. **URL을 주면 브라우저로 직접 캡처**하고, 그 결과를 **LLM이 축소
없이 읽을 수 있는 크기로 잘라서** `<이름>_output/` 폴더에 순서대로 저장한다.

```bash
imgslice 'https://example.com/아주-긴-글'   # 캡처 + 슬라이싱 한 번에
imgslice screenshot.png                      # 이미 있는 이미지 자르기
```

## 설치

```bash
git clone <이 저장소>
cd image_slicer_for_llm
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[web]"   # URL 캡처까지 쓰려면 [web]
.venv/bin/playwright install chromium          # 브라우저 엔진 (한 번만)
```

로컬 이미지만 자를 거면 `-e .` 만 해도 된다 (playwright 불필요).

어느 폴더에서나 `imgslice` 로 쓰려면 PATH에 링크를 건다:

```bash
ln -sf "$PWD/imgslice" ~/.local/bin/imgslice
```

래퍼가 심볼릭 링크를 따라가 프로젝트 위치를 스스로 찾으므로 어디에 걸어도 된다.

## 사용법

### URL에서 바로

```bash
imgslice 'https://m.blog.naver.com/PostView.naver?blogId=xxx&logNo=123'
imgslice 'https://example.com/long' -p openai      # 대상 서비스 지정
imgslice 'https://example.com/long' --width 500    # 모바일 레이아웃으로
imgslice 'https://example.com/long' --show         # 브라우저 창 띄워서 확인
```

> 주소에 `&` 가 들어가면 **반드시 따옴표로 감싸야 한다** (zsh에서 `&`는 백그라운드 실행).

### 로컬 이미지에서

```bash
imgslice                          # 현재 폴더의 이미지 목록에서 골라서
imgslice page.png                 # page_output/ 에 page_01.png, page_02.png ...
imgslice *.png --force            # 여러 장 한 번에, 기존 결과 덮어쓰기
imgslice page.png --dry-run       # 파일을 만들지 않고 자르는 위치만 확인
imgslice page.png -f jpeg -q 88   # 용량이 부담될 때
imgslice page.png --open          # 끝나면 Finder로 출력 폴더 열기
```

실행 예시:

```
■ https://m.blog.naver.com/PostView.naver?blogId=xxx&logNo=123
  프리셋 claude (긴 변 1568px / 최대 1.15MP) · 조각 1200x958 · 겹침 60px · 여백 맞춤 켬
  페이지 여는 중...
  끝까지 스크롤해서 이미지 로딩 중...
  고정/스티키 요소 4개 숨김 (조각마다 겹쳐 나오는 것 방지)
  페이지 높이 30,785px · 뷰포트 1200x958 @2x
  조각 32개 캡처 중...
```

## 프리셋

`--list-presets` 로 현재 값을 확인할 수 있다.

| 프리셋 | 긴 변 | 총 픽셀 | 권장 조각 | 근거 |
| --- | --- | --- | --- | --- |
| `claude` (기본) | 1568px | 1.15MP | 원본 폭 x 계산값 | 문서 확인됨 |
| `claude-hires` | 2576px | 3.75MP | 원본 폭 x 계산값 | 문서 확인됨 |
| `openai` | 2048px | 1.57MP | 768x2048 | 문서 확인됨 |
| `gemini` | 2304px | 1.77MP | 768x2304 | **공식 미확인** |

### 왜 이 숫자인가

- **Claude** — 긴 변 제한과 총 픽셀 제한을 **동시에** 만족해야 축소되지 않는다. 그래서
  조각 높이는 `긴 변 한계`와 `총 픽셀 한계 ÷ 가로폭` 중 작은 쪽으로 정해진다. 폭 1200px면
  높이는 958px가 된다. `claude-hires` 는 고해상도 입력을 지원하는 최신 모델용이다.
- **OpenAI** — `detail=high` 파이프라인은 ① 2048x2048 박스에 맞춰 축소 → ② **짧은 변을
  768px로** 리사이즈 → ③ 512x512 타일로 분할, 순서로 동작한다. 즉 짧은 변이 768px가
  아니면 무조건 재샘플링된다. 그래서 폭을 768px로 고정한다.
- **Gemini** — 768x768 타일 기반이라고 알려져 있으나 **공식 문서에서 확인하지 못했다.**
  타일 크기에 맞춰 보수적으로 잡아둔 값이니, 정확한 스펙을 아신다면
  `--max-edge` / `--max-pixels` 로 덮어쓰거나 이슈로 알려주시면 좋겠다.

토큰 추정치도 프리셋마다 다른 방식으로 계산한다 (Claude는 픽셀÷750, OpenAI는
`85 + 170 x 타일수`, Gemini는 `258 x 타일수`). 어디까지나 근사치다.

## 동작 방식

### URL 캡처

브라우저의 전체 페이지 캡처를 쓰지 않는다. **어차피 잘라서 쓸 거라면 한 장으로 찍을 이유가
없기 때문이다.** 대신 뷰포트를 조각 크기에 맞춰놓고 스크롤하며 찍는다.

1. 조각 크기(예: 1200x958)를 프리셋에서 계산하고 그 크기로 브라우저 뷰포트를 연다.
2. 페이지를 끝까지 스크롤한다 → **lazy loading 이미지가 전부 로딩된다.**
3. `data-src` / `data-lazy-src` 같은 지연 로딩 속성을 강제로 풀고, 모든 이미지가 로딩될
   때까지 기다린다.
4. `position: fixed/sticky` 요소를 숨긴다 → 헤더가 모든 조각에 겹쳐 나오지 않는다.
5. 스크롤 위치를 **균등하게 배분**해서 순서대로 찍는다 → 길이 제한 없음, 자투리 조각 없음.
6. 2배 해상도로 찍어 1배로 줄인다 → 다운샘플링 효과로 글자가 더 또렷해진다.

### 이미지 자르기

1. **폭 맞추기** — 프리셋 권장 폭(또는 `--width`)보다 넓으면 축소한다. 원본 해상도를
   유지하려면 `--wide split` 으로 좌우 열 분할을 쓴다.
2. **균등 분할** — 조각 개수를 최소로 하면서 모든 조각 높이가 같도록 나눈다. 마지막에
   몇 픽셀짜리 자투리가 생기지 않는다.
3. **여백 맞춤(smart cut)** — 자르는 선이 글자 줄 한가운데를 지나가지 않도록, 각 경계를
   위쪽 80px 안에서 가장 여백에 가까운 가로줄로 당긴다. 가로줄별 픽셀 분산으로 판단하며,
   마땅한 여백이 없으면 원래 위치를 유지한다. `--no-smart-cut` 으로 끌 수 있다.
4. **겹침** — 조각끼리 기본 60px 겹치게 잘라 경계에 걸린 내용이 사라지지 않게 한다
   (`--overlap`). 여백에서 깔끔하게 잘린 경우엔 겹침이 절반까지 줄어들 수 있다.

## 출력물

```
<이름>_output/
├── manifest.json      # 조각 순서 · 원본 좌표 · 크기 · 예상 토큰 수
├── <이름>_01.png
├── <이름>_02.png
└── ...
```

`manifest.json` 에는 각 조각이 원본(또는 페이지)의 어느 좌표에 해당하는지 들어 있어서,
LLM이 짚어준 위치를 되찾을 때 쓸 수 있다. 필요 없으면 `--no-manifest`.

## 안전장치

- 출력 폴더가 비어있지 않으면 그냥 실패한다. 덮어쓰려면 `--force` (이때도 해당 대상의
  조각 파일과 `manifest.json` 만 지운다).
- 조각 하나가 5MB를 넘으면 경고한다 (업로드 용량 제한 → `-f jpeg` 권장).
- EXIF 회전 정보를 실제 픽셀에 반영한 뒤 자른다.
- 무한 스크롤 페이지에서 영원히 돌지 않도록 스크롤·조각 수에 상한이 있다.

## 알려진 한계

- 로그인이 필요한 페이지는 캡처할 수 없다.
- 무한 스크롤 페이지는 중간에서 멈추고 경고를 띄운다.
- 스크롤 컨테이너가 `window` 가 아닌 페이지(일부 SPA)는 제대로 캡처되지 않을 수 있다.
- 프리셋 수치는 서비스 정책에 따라 언제든 바뀔 수 있다. 특히 `gemini` 는 공식 확인이
  안 된 값이다.
